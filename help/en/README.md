# Labs Studio help

Labs Studio makes images in batches: you give it a list of prompts, it runs them one after another and saves every result in a folder. Out of the box it uses **Google Flow** through your own signed-in Chrome window.

The same pages open inside the app under **Help** in the sidebar. Every page also has a small **?** button in its top-right corner that opens its topic.
